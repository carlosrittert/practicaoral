ACIPOL — Sorteo oral por tarjetas v3

Ingresa el nombre del postulante, elige una tarjeta numerada y el sistema sorteará preguntas nuevas cada vez que selecciones una tarjeta.

La evaluación es flexible: acepta respuestas con palabras propias y no exige bajada institucional cuando la pregunta es conceptual.

Inicio

Al iniciar aparecerán tarjetas numeradas. Cada vez que selecciones una tarjeta, se sortearán 5 preguntas nuevas del banco total: 2 obligatorias y 3 alternativas, de las cuales deberás elegir solo una.
